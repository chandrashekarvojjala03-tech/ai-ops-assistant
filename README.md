# AI Ops Assistant

AI-powered DevOps monitoring assistant built with Flutter and FastAPI.

Features
- Real-time CPU, RAM, and Disk monitoring
- Alert generation for system issues
- Anomaly detection
- Incident insights
- Metrics history tracking
- Full-stack architecture

Tech Stack
Frontend: Flutter  
Backend: FastAPI  
Languages: Dart, Python
